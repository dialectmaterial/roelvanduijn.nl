# roelvanduijn.nl: notes for coding agents

This repository is generated output, served by GitHub Pages; pushing `main` publishes the site. Don't edit the HTML pages by hand: they are built from the data JSONs here (`posts.json`, `books.json`, `photos.json`, …) by a generator kept in a separate local-only source archive. Its `AGENTS.md` describes the pipeline, the manual Facebook import and the content rules; find it through the maintainer's project index.

- `git pull` first: GitHub itself sometimes commits CNAME changes.
- Commit messages are Dutch for content updates (for example `Roel en Rusland 196 (16 november): …`).
- Keep archival material and personal data out of this public repository; the local `.cloudflare/` CLI cache is ignored for that reason.
